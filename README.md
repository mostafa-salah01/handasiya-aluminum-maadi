# الشركة الهندسية للألوميتال - عرب المعادي، القاهرة

الموقع الرسمي للشركة الهندسية للألوميتال، المتخصصة في توريد وتصنيع وتركيب أعمال الألوميتال (شبابيك، أبواب، واجهات، مطابخ، تندات وشيش حصيرة، وبيع قطاعات الألوميتال) في عرب المعادي والمعادي وزهراء المعادي ودجلة المعادي وجميع مناطق القاهرة ومحافظات مصر.

## 2. طريقة تعديل بيانات الموقع من ملف `js/data.js`

الموقع مصمم بنظام بيانات مركزي، حيث تتواجد كافة البيانات والنصوص والأرقام والروابط في ملف واحد هو `js/data.js`:

### أ. تعديل أرقام الهاتف والواتساب
توجد متغيرات واضحة للأرقام في `js/data.js`:
```javascript
// الرقم الأساسي (مكالمات + واتساب)
PHONE_1_DISPLAY: '01141633199',
PHONE_1_TEL: 'tel:+201141633199',
WHATSAPP_NUMBER: 'wa.me/201141633199',
WHATSAPP_BASE_URL: 'https://wa.me/201141633199',

// الرقم الإضافي (مكالمات فقط)
PHONE_2_DISPLAY: '01128482761',
PHONE_2_TEL: 'tel:+201128482761',
```
- زر "اتصل الآن" في الموقع يفتح تلقائياً نافذة سهلة تتيح للزائر الاختيار المباشر بين الرقمين بضغطة زر.
- زر واتساب العائم الثابت وجميع أزرار طلب المعاينة وعروض الأسعار موجهة حصرياً إلى الرقم الأساسي `01141633199`.

### ب. تعديل قائمة الإدارة
يمكن إضافة أو تعديل أعضاء الإدارة من خلال مصفوفة `MANAGEMENT`:
```javascript
MANAGEMENT: [
  {
    ar: 'وائل رمضان لغا',
    en: 'Wael Ramadan Lagha'
  },
  {
    ar: 'م/ عمار وائل لغا',
    en: 'Eng. Ammar Wael Lagha'
  },
  {
    ar: 'م/ عبد الرحمن لغا',
    en: 'Eng. Abdul Rahman Lagha'
  }
]
```
تظهر الأسماء تلقائياً في صفحة "تواصل معنا" وصفحة "من نحن" وفي الفوتر الرسمي.

### ج. تعديل العنوان واستبدال [اسم الشارع]
العنوان مقسم إلى تفاصيل الشارع والمنطقة:
```javascript
ADDRESS_STREET_AR: '9 شارع [اسم الشارع]، فرع شارع محمد نور الدين',
ADDRESS_STREET_EN: '9 [Street Name], off Mohamed Nour El-Din St',
ADDRESS_AREA_AR: 'عرب المعادي، القاهرة',
ADDRESS_AREA_EN: 'Arab El-Maadi, Cairo',
```
- **آلية العرض الذكية**: ما دام النص `[اسم الشارع]` موجوداً بين قوسين، يُعرض في واجهة الموقع "عرب المعادي، القاهرة" فقط لتفادي ظهور الأقواس غير المكتملة.
- عندما تعرف اسم الشارع الفعلي، استبدل فقط النص `[اسم الشارع]` باسم الشارع الحقيقي (مثال: `'9 شارع النصر، فرع شارع محمد نور الدين'`) وسيظهر العنوان الكامل فوراً في كل أنحاء الموقع.

### د. تعديل الخريطة ورابطها
لتحديث موقع الخريطة وإحداثياتها:
```javascript
MAP_EMBED_URL: 'https://www.google.com/maps?q=Mohamed+Nour+El+Din+St,+Arab+El-Maadi,+Cairo,+Egypt&output=embed',
MAP_URL: 'https://www.google.com/maps/search/?api=1&query=Mohamed+Nour+El+Din+St%2C+Arab+El-Maadi%2C+Cairo%2C+Egypt',
MAP_IMAGE: './images/location-map.jpg',
```
- يعرض الموقع كارت صورة جذاباً للخريطة قابل للضغط وزر "افتح الموقع على خريطة جوجل"، مع الـ iframe التفاعلي.
- في حال عدم وجود ملف صورة الخريطة، يتحول العرض تلقائياً ودون أي خطأ إلى الخريطة التفاعلية مع الزر المباشر.

### هـ. ربط نموذج التواصل بـ Formspree
لتلقي رسائل وطلبات المعاينة على بريدك الإلكتروني عبر [Formspree](https://formspree.io):
```javascript
FORMSPREE_URL: 'https://formspree.io/f/YOUR_FORM_ID',
```

## 3. طريقة الرفع على GitHub وتفعيل الاستضافة المجانية (GitHub Pages)

الموقع مبني بتقنيات الويب القياسية الخالصة (**HTML5 + CSS3 + Vanilla JavaScript**)، بدون الحاجة لأي أدوات بناء أو إعدادات خادم:

1. ارفع التغييرات إلى مستودع GitHub:
   ```bash
   git add .
   git commit -m "تحديث الموقع الرسمي للشركة الهندسية للألوميتال"
   git push origin main
   ```
2. ادخل على صفحة المستودع على **GitHub.com**.
3. افتح التبويب **Settings** (الإعدادات).
4. من القائمة الجانبية، اختر **Pages**.
5. تحت قسم **Build and deployment**:
   - **Source**: اختر **Deploy from a branch**.
   - **Branch**: اختر الفرع `main` و المجلد `/ (root)`.
   - اضغط على **Save**.
6. سيعمل الموقع مباشرة على رابط GitHub Pages الخاص بك.

## 4. الميزات التقنية المطبقة

- **ثنائي اللغة بالكامل (العربية والإنجليزية)** مع حفظ التفضيل في `localStorage`.
- **RTL متكامل** واستخدام CSS Logical Properties لضبط الاتجاهات والأبعاد.
- **عرض رقمي الاتصال مع نافذة اختيار سريعة** تراعي معايير سهولة الاستخدام وحجم لمس 44px كحد أدنى.
- **خلفية فيديو الهيرو عالية الوضوح** مع إمكانية التشغيل التلقائي وبديل صور فوري عند تفعيل وضع توفير البيانات.
- **نطاق تغطية جغرافي محكم يبدأ بـ عرب المعادي** يليه المعادي وزهراء المعادي ودجلة المعادي وباقي مناطق القاهرة وكل المحافظات.
- **بيانات هيكلية متكاملة (Schema.org)** من نوع `HomeAndConstructionBusiness` تتضمن الرقمين وموقع الخريطة والخدمات ونطاق الخدمة الرسمي.
